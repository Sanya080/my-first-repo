## Про проєкт

Цей репозиторій створено в рамках **практичних робіт** з курсу по Git. Тут я навчився:

- Створювати та клонувати репозиторії
- Робити коміти та відправляти зміни через `git push`
- Працювати з гілками (`branch`) та зливати їх (`merge`)
- Вирішувати конфлікти злиття
- Керувати завданнями через **GitHub Issues**
- Оформлювати документацію за допомогою **Markdown**

## Основні команди Git

```bash
# Ініціалізація репозиторію
git init

# Додати файли до індексу
git add .

# Зробити коміт
git commit -m "Повідомлення коміту"

# Відправити зміни на GitHub
git push origin main

# Створити нову гілку
git checkout -b назва-гілки
```
